วางไฟล์เพลงสำหรับ "โซนที่ 2 — พื้นที่งานวัดทั้งหมด (นอกโซนเวทีคอนเสิร์ต)" ลงในโฟลเดอร์นี้ (public/audio-festival/)
รองรับไฟล์ .mp3, .ogg, .m4a, .wav

ระบบจะดึงทุกไฟล์ในโฟลเดอร์นี้มาเล่นวนต่อเนื่องอัตโนมัติคลอทั่วพื้นที่งานวัด
(หน้าซุ้มประตู, ถนนคนเดินฝั่งล่าง, ศาลาพระพุทธรูป, ลานปล่อยโคม, อุโมงค์ไฟ, ร้านกระทง, ท่าน้ำ และสวนทั้งหมด)
และจะเฟดเงียบลงอัตโนมัติเมื่อผู้เล่นเดินเข้าสู่โซนเวทีคอนเสิร์ต (X <= 3.5, Z <= 6.5) เพื่อไม่ให้เสียงเพลงตีกัน

หมายเหตุ: หลังนำไฟล์เพลงมาวางในโฟลเดอร์นี้แล้ว บอกให้ผมช่วย Push + Deploy ขึ้น Render ได้เลยครับ
