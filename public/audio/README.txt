วางไฟล์เพลง (.mp3, .ogg, .m4a, .wav) ลงในโฟลเดอร์นี้ (public/audio/)
เวทีคอนเสิร์ตจะดึงทุกไฟล์ในโฟลเดอร์นี้มาเล่นวนต่อเนื่องอัตโนมัติเรียงตามชื่อไฟล์ (เช่น 01_song.mp3, 02_song.mp3)
พร้อมระบบเสียง 3D แท้ (เดินใกล้เวทีดัง เดินไกลเวทีเบา แยกเสียงซ้าย-ขวาตามมุมกล้อง) โดยผู้เล่นไม่สามารถกดเปลี่ยนเพลงเองได้

หมายเหตุ: หลังเพิ่มไฟล์เพลงลงในโฟลเดอร์นี้แล้ว ให้ Push ขึ้น GitHub และกด Manual Deploy บน Render
(หากยังไม่มีไฟล์ในโฟลเดอร์นี้ ระบบจะเล่นดนตรีงานวัด 120 BPM อัตโนมัติไปก่อน)
